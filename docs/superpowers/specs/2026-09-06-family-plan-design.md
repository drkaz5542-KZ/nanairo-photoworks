# ファミリープラン ページ作り込み — 設計

作成日: 2026-09-06

## 目的

`plan-family.html` は現在「Coming Soon」のプレースホルダで、トップページのサービスカードも「近日公開予定」のままリンクが無い。ファミリーフォトの料金・内容が確定したため、マタニティ／ニューボーンと同等の詳細ページとして公開する。

## 確定した内容

### プラン

| | ベーシック | プレミアム |
|---|---|---|
| 通常価格（税込） | ¥39,800 | ¥49,800 |
| リピーター価格（税込） | ¥22,800 | ¥39,800 |
| データ枚数 | 60枚〜 | 90枚〜 |
| 撮影場所 | 1箇所 | 2箇所（例：神社 → レストラン） |
| バッジ | 「おすすめ」 | なし |

- 「おすすめ」バッジは**ベーシック**に付ける。価格のハードルを下げて入口を広げる意図。
- 実績の裏付けが必要な「人気No.1」ではなく「おすすめ」という表現を使う。

### 共通条件

- 土日祝の撮影は +¥5,500（税込）
- リピーター価格の対象は、過去に七彩 Photo Works で撮影したことがある方**全員**（マタニティ・ニューボーン・ファミリーを問わない）

### 対象シーン

お宮参り / お食い初め・百日祝い / 七五三 の3つ。バースデー・家族記念は今回謳わない。

### 出張エリア

大阪・和歌山・兵庫（既存の構造化データ `areaServed` と同じ）。

### ファミリー専用 Instagram

`https://www.instagram.com/nanairo_anniversary/`

共有トークン付きURL（`?stkn=...`）は個人向けのため、サイトには載せない。

### 配色

**現行のベージュ系で完全統一する。** ファミリー用 Instagram は水色トーンだが、サイト側は色を振らない。ヘッダー・フッターが全ページ共通（ベージュ＋こげ茶）のため、本文だけ色を変えると上下で色が割れる。Instagram は導線リンクとして置くのみ。

## 変更内容

### 1. `plan-family.html` の全面刷新

`coming-section` を削除し、`plan-maternity.html` / `plan-newborn.html` と同じ構造・CSS に揃える。

**セクション構成:**

1. ヒーロー — `Family Plan` / ファミリープラン / 「お宮参り・お食い初め・七五三 — ご家族の節目を、記念の一枚に」
2. 対象シーン — 3つを横並びで提示
3. プランカード ×2 — ベーシック（「おすすめ」バッジ付き）／プレミアム
4. リピーター価格の注記 — 「※過去に七彩 Photo Works で撮影された方は、リピーター価格でご利用いただけます」
5. 土日祝の注記 — 既存の `.weekend-note` を流用
6. ファミリー専用 Instagram への導線
7. CTA — 公式LINE（既存の `.plan-cta` を流用）

**プランカードの価格表示（新要素）:**

通常価格を `.plan-price` で大きく表示し、その下にリピーター価格を `--color-bg-alt` の帯として置く。ラベル「リピーター」を左、金額を右に配置し、金額は `--color-accent-dark`。既存の `.plan-price` / `.plan-features` はそのまま流用し、リピーター帯のみ新規クラス（`.plan-repeat`）を追加する。

**写真:**

`images/Gallery_11.jpg`（兄弟＋赤ちゃん）と `images/Top_6.jpg`（家族集合）を仮置きする。ファミリー撮影の写真が揃い次第、差し替える。

**構造化データ:**

既存の `Service` + `BreadcrumbList` を維持し、`Offer` として2プランの価格を追加する。

### 2. `index.html` サービスカードの修正

- 説明文にお食い初めを追加
